# Contributing to Globe Trekker Web

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository.
2. Clone your fork.

```bash
git clone https://github.com/pawansuthar01/globe_trekker-web.git
```

3. Install dependencies.

```bash
npm install
```

4. Start the development server.

```bash
npm start
```

## How to Contribute

You can contribute by:

* Fixing bugs
* Improving the UI/UX
* Optimizing performance
* Adding new travel features
* Improving accessibility
* Enhancing documentation
* Writing tests

## Pull Request Guidelines

* Keep pull requests focused on a single change.
* Write clear commit messages.
* Test your changes before submitting.
* Update documentation if needed.

## Code Style

* Use meaningful variable names.
* Follow consistent formatting.
* Remove unused code.
* Keep components modular and reusable.

## Reporting Issues

When reporting an issue, please include:

* A clear description
* Steps to reproduce
* Expected behavior
* Screenshots (if applicable)

## Community

Please be respectful and constructive. We welcome contributors of all experience levels and appreciate every contribution.

Happy coding! 🚀
